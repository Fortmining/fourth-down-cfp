# What If? multi-game sandbox release candidate

Scope: up to 16 distinct verified upcoming fixtures; choose either winner, clear/remove picks, compare overall and supported conference records. Shared confirmed game IDs establish effects on prior opponents, including competing teams that are not selected. The public interface shows factual record/evidence changes only: no experimental selection scores, model ordering, projected qualifiers, brackets or probabilities. This deliberately does not expose PR #19's unsuccessful committee-selection candidate.

The sandbox reuses confirmed snapshot validation and existing released resume data. Both sides of a fixture must have reconciled records and reciprocal schedule evidence. Unsupported/unassigned opponents, expired source evidence and already-confirmed results are withheld. Snapshot dates remain explicit; they are not relabeled fresh observations. Current scoreboard failure or pending reconciliation withholds the display. Games becoming Final are removed on the existing visible-page refresh mechanism. Choices are local memory only; no user or source state is written.

Entry: CFP navigation → What If? (`/scenarios`). Existing AppFrame provides branding, theme preferences, navigation and mobile layout. Existing single-game scenarios remain unchanged. PR #19 stays isolated.

Operational scope: initial/visible-page refresh uses one catalog GET plus the existing live-score GET; winner toggles, search and clear use no network. Refresh is the existing minute/resume helper, not a new server or notification schedule. The catalog uses the existing five-minute shared resume cache and existing 300-display-read/day admission cap. A cold shared-cache read can reserve seven Redis commands and one meter mutation; this is not a zero-write claim or a new billing measurement. No new Redis keys, publisher API, service, credential or backend ingestion interval. Visitor/instance amplification remains bounded by existing fail-closed admission and must be observed during controlled rollout, not claimed newly benchmarked.

Five focused arithmetic/evidence tests pass. Production build/type checking and lint pass. Browser checks cover desktop/iPhone sizes, 16-game cap, peer effects, Final pruning, source failures, overflow and accessibility using explicitly private synthetic boundary cases over genuine baseline records. Additional review screenshots use the saved November 1, 2026 full confirmed public snapshot; they are historical replay, not live evidence. No Preview or production deployment has been performed; branch auto-deployment disabled.

Exclusions: official poll changes, selection predictions, numeric probabilities, conference-title qualification/tiebreaker resolution, uncertain FCS/other fixtures without both reconciled participants. Conference record changes do not certify a championship place.

Final review corrections: unknown kickoff times are labelled TBD; selected teams appear before indirectly affected opponents. Current scoreboard availability is required before displaying scenarios. Official rank/source/publication code, Game Center and single-game scenario code remain unchanged.
