# One-game conditional records — development candidate

Upcoming Game Center pages gain an on-demand “What would a win change?” panel. Either winner shows the two teams' conditional overall and, where supported, conference records. Published poll positions are context only. No changed resume ordering, projected qualifier, bracket, championship berth or probability is asserted.

Uses the existing materialized public resume display and shared five-minute cache. A narrow read-only route returns only this game's two rows/outcomes rather than sending all 138 team histories to the browser. No new producer, polling timer, publisher request, Redis key, content/ledger write, credential or service. Cold cached-display reads retain the existing meter mutation; they are not zero-write operations. One request when opened; winner toggles and reopening use the same in-page packet. Cold route fills can incur the existing metered display read (the unchanged protocol reserves seven commands and one meter mutation per miss, with at most 300 display reads/day). This is a reservation, not a new measured bill. Cross-instance amplification and billed CPU are not newly measured.

Requires a dated, complete 2026 snapshot, matching reciprocal future-fixture evidence, reconciled win/loss counts and no duplicate result evidence. Any already-counted game is withheld even if another feed still lists it as upcoming/in progress. Invalid/future/older-than-seven-days snapshots fail safely. Conference effects require the snapshot's conference-game evidence and a usable conference record. Future official editions are not shown. Inputs are immutable; no hypothetical result enters the confirmed ledger.

A dated snapshot can be older than the current scoreboard; labels explicitly say snapshot baseline, not current live verification. Only this single result is varied and other results are held unchanged. This initial feature is record-impact arithmetic, not a calibrated CFP prediction model. Further selection/order scenarios must reuse the validated engine and separate official polls.
